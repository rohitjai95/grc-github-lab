# PCI DSS Evidence Checklist

Use this checklist to collect, review, and document evidence for PCI DSS control validation. Record the assessment period, system scope, evidence owner, and reviewer for each item.

## Access Control

| Evidence item | Review focus | Status | Notes |
| --- | --- | --- | --- |
| User access list for CDE systems | Active users are authorized, role-appropriate, and tied to business need | Not started |  |
| Privileged access review | Admin accounts are approved, limited, and reviewed periodically | Not started |  |
| Joiner, mover, leaver samples | Access changes are completed timely and supported by tickets or approvals | Not started |  |
| MFA configuration evidence | MFA is enforced for administrative and remote access | Not started |  |
| Password and authentication settings | Settings align with PCI DSS requirements and internal policy | Not started |  |

## Logging and Monitoring

| Evidence item | Review focus | Status | Notes |
| --- | --- | --- | --- |
| Audit log configuration | Critical systems generate logs for user, admin, and security events | Not started |  |
| Log retention evidence | Logs are retained for the required period and protected from alteration | Not started |  |
| Daily log review or alert review samples | Reviews are performed, documented, and escalated when needed | Not started |  |
| SIEM or monitoring rule inventory | Rules cover in-scope systems and key PCI-relevant events | Not started |  |
| Incident escalation records | Alerts and incidents show timely triage, ownership, and closure | Not started |  |

## Vulnerability Management

| Evidence item | Review focus | Status | Notes |
| --- | --- | --- | --- |
| Internal vulnerability scan results | Scans cover in-scope assets and findings are tracked to resolution | Not started |  |
| External ASV scan attestations | Passing scans are available for each required quarter | Not started |  |
| Remediation tickets | High-risk findings are remediated within policy timelines | Not started |  |
| Patch management reports | Security patches are evaluated, approved, and deployed timely | Not started |  |
| Penetration test report and retest evidence | Scope includes CDE and segmentation controls where applicable | Not started |  |
